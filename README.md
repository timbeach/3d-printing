# 3D Printing

Parametric OpenSCAD designs with ready to print STLs. MIT licensed.

## Projects

- [rava8-totem](rava8-totem/): a desk totem enclosure for the RAVA8 avalanche
  noise true random number generator, modeled from the board's EAGLE design
  files. Board stands vertical behind a sliding translucent diffuser with room
  for an LED behind the panel. Draft status: not yet test printed.
